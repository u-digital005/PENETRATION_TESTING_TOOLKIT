# PENETRATION_TESTING_TOOLKIT:

So basically, penetration testing means testing a computer system or network to find its weak points before a bad person finds them. It is like when someone tries to break into your own house to check if the locks are strong enough. In simple words, we are acting like a hacker, but in a good and legal way.

This toolkit is a Python based project that has three main tools inside it — a Port Scanner, a Banner Grabber, and a Brute Force Attacker. All three tools are used by security professionals to check if a system is safe or not.

How it works:

The first tool is the Port Scanner. Every computer has ports, like doors. Some doors are open and some are closed. This tool checks which ports are open on a target computer. It uses threading so many ports are checked at the same time, which makes it faster. It also shows the service name like FTP, HTTP, SSH etc. for each open port.

The second tool is the Banner Grabber. When you connect to an open port, sometimes the server sends back a small message called a banner. This banner has information about the software running on that port, like its name and version. Hackers use this to find which version of software is running and then check if that version has any known problems.

The third tool is the Brute Force Attacker. This tool tries to login to an FTP server by trying many passwords one by one from a wordlist file. It is used to check if weak passwords are being used on the server.

The project also uses colorama library to show output in different colors so it is easy to read. Results from the port scanner can also be saved to a text file.
